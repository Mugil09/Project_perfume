# Project Perfume

Project Perfume is a static website showcasing a curated collection of perfumes for both men and women. This project focuses on clean design, attractive product visuals, and a responsive layout using only HTML and CSS.

## 🌟 Features

- Responsive layout suitable for desktop and mobile
- High-quality product imagery
- Gender-based perfume collections
- Promotional banner for enhanced visual appeal
- Organized styling via external CSS

## 📁 Project Structure

Project_Perfume/ 
├── index.html # Main landing page 
├── style.css # Stylesheet for layout and design 
├── *.avif / *.jpg / *.png # Product and banner images

## 🛠️ Technologies Used

- HTML5
- CSS3
- AVIF/JPEG/PNG image formats
